# Запуск

Скачайте `faceit-bypass.zip` на странице [Releases](https://github.com/ravshansher23/zapret_faceit/releases). Кнопка Code на главной странице скачивает исходники, для игры нужен архив из Releases.

1. Распакуйте архив.
2. В комнате матча FACEIT нажмите Copy.
3. Запустите `Запуск.bat`.
4. Подтвердите запрос администратора.
5. Подключайтесь к матчу после строки «обход запущен».

Если не соединяется, закройте обход через `Стоп.bat` и запустите `Запуск ALT.bat`.

Папка `bin` уже лежит в проекте, отдельно zapret-discord-youtube запускать не нужно.

Исходный код распространяется по лицензии MIT. Файлы в `bin/` остаются под лицензиями своих проектов, подробности в `LICENSE`.
