# Запуск

Скачайте `faceit-bypass.zip` на странице [Releases](https://github.com/ravshansher23/zapret_faceit/releases). Кнопка Code на главной странице скачивает исходники, для игры нужен архив из Releases.

1. Распакуйте архив.
2. В комнате матча FACEIT нажмите Copy.
3. Запустите `Запуск.bat`.
4. Подтвердите запрос администратора.
5. Выключите VPN и подключайтесь к матчу после строки «обход запущен».

При запуске папка добавляется в исключения Защитника Windows. Если ругается другой антивирус, восстановите удалённые им файлы из карантина и добавьте эту папку в исключения вручную. `winws.exe` и `WinDivert64.sys` он часто считает угрозой, хотя это драйвер обхода.

Обход идёт не только на скопированный IP. Матч ещё ходит на релеи Steam и сервисы FACEIT, поэтому закрыты порты UDP 27000–28100 и сайты Steam. `Запуск.bat` режет большие пакеты, чтобы фильтр не видел протокол целиком. Если сервер не отвечает совсем, закройте обход через `Стоп.bat` и запустите `Запуск ALT.bat`.

Папка `bin` уже лежит в проекте, отдельно zapret-discord-youtube запускать не нужно.

Исходный код распространяется по лицензии MIT. Файлы в `bin/` остаются под лицензиями своих проектов, подробности в `LICENSE`.
